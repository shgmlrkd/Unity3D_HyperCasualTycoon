# Food Tycoon

## 게임 소개

**Food Tycoon**은 레스토랑을 운영하며 음식을 준비하고 손님에게 제공하여 수익을 얻고, 직원과 시설을 관리하며 레스토랑을 성장시키는 **3D 하이퍼 캐주얼 + 타이쿤 게임**입니다.

플레이어는 손님에게 음식을 제공하고 획득한 수익을 이용해 새로운 시설을 해금하거나 직원을 고용하고 업그레이드하여 레스토랑을 확장해 나가는 것을 목표로 합니다.

---

# 조작 방법

| **기능** | **조작키** |
| --- | --- |
| 이동 / 발판 상호작용 | **W / A / S / D** |
| 업그레이드 / 직원 고용 | **마우스 좌클릭** |
| 설정창 열기 | **ESC** 또는 좌측 상단 톱니바퀴 |

---

# 게임 진행

* 플레이어는 음식 준비 공간에서 음식을 획득하여 손님에게 서빙할 수 있습니다.
* 손님 NPC는 레스토랑에 입장하여 자리에 앉고 음식을 주문합니다.
* 주문한 음식이 제공되면 손님은 음식을 섭취한 후 돈을 드롭합니다.
* 획득한 돈을 이용하여 직원과 시설을 해금하고 레스토랑을 확장할 수 있습니다.
* 레스토랑에 필요한 시설은 해금 비용을 지불하여 새로운 공간을 사용할 수 있습니다.

---

# 주요 시스템

## 1. 플레이어

* **W / A / S / D**를 통해 이동할 수 있습니다.
* 음식을 확득하고 테이블로 이동하여 손님에게 직접 서빙할 수 있습니다.
* 음식, 쓰레기통, 업그레이드 시설 등과 상호작용할 수 있습니다.

## 2. 손님

* 손님은 레스토랑에 입장하여 빈 테이블을 찾아 자리에 앉습니다.
* 테이블에 앉은 후 음식을 주문하고 주문한 음식을 받을 때까지 기다립니다.
* 음식을 섭취한 후 돈을 드롭하고 레스토랑을 떠납니다.

## 3. 직원

* 플레이어는 직원을 고용하여 레스토랑 운영을 보조할 수 있습니다.
* 직원은 현재 상황에 따라 음식을 가져오거나 손님에게 음식을 서빙합니다.
* 직원 업그레이드를 통해 한 번에 운반할 수 있는 음식의 수량을 늘릴 수 있습니다.

## 4. 시설 해금 및 업그레이드

* 특정 발판과 상호작용하여 새로운 시설을 해금할 수 있습니다.
* 해금에 필요한 비용을 지불하면 잠겨 있던 공간과 시설을 사용할 수 있습니다.
* 시설과 직원을 업그레이드하여 레스토랑의 운영 효율을 높일 수 있습니다.
